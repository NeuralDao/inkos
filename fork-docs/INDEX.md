# Документация форка InkOS

Точка входа для нового рабочего чата. Репозиторий: **NeuralDao/inkos**; рабочая ветка: **custom/main**.

## Порядок чтения

1. [CURRENT_STATE.md](./CURRENT_STATE.md) — факты, проверенная версия, блокеры и следующий шаг.
2. [ROADMAP.md](./ROADMAP.md) — приоритеты и зависимости.
3. [ARCHITECTURE.md](./ARCHITECTURE.md) — краткая карта реальных модулей InkOS 2.0, точки входа, известные ограничения.
4. [LANGUAGE_AUDIT.md](./LANGUAGE_AUDIT.md) — детальный аудит языковых инструкций и маршрутов, статус рисков, тестовый план.
5. [DECISIONS.md](./DECISIONS.md) — принятые решения и причины.
6. [WORKFLOW.md](./WORKFLOW.md) — правила работы пользователя, ChatGPT и Codex.

Затем изучить связанные GitHub Issues/PR и **код** нужной ветки. Для технических выводов указывать проверенный коммит. Если документация противоречит реализации, приоритет у кода; расхождение следует зафиксировать.

## Границы документации

- Фиксировать **факты, решения, ограничения, статус и ссылки**, не переносить переписку.
- Документы ведёт ChatGPT; только Codex изменяет код, конфигурации, тесты, скрипты и CI.
- Дополнительные файлы создавать по мере необходимости.
- Не считать возможность из README доказательством её работоспособности: сверять с реализацией и, при необходимости, локальной проверкой.
- Не помещать API-ключи, приватные рукописи, пользовательские настройки и другие чувствительные данные в публичный GitHub.

**GitHub не отражает незакоммиченные файлы и текущее состояние локального ПК.**
