# Документация форка InkOS

Это точка входа для нового рабочего чата ChatGPT. Репозиторий: **NeuralDao/inkos**; рабочая ветка: **custom/main**.

## Читать в таком порядке

1. [CURRENT_STATE.md](./CURRENT_STATE.md) — что подтверждено, что не проверено, блокеры и ближайший шаг.
2. [ROADMAP.md](./ROADMAP.md) — направления, приоритеты и зависимости.
3. [DECISIONS.md](./DECISIONS.md) — устойчивые решения и причины.
4. [WORKFLOW.md](./WORKFLOW.md) — как работают пользователь, ChatGPT и Codex.

Затем открыть связанные GitHub Issues/PR и **фактический код** нужной ветки. Указывать проверенный коммит. Если документы расходятся с кодом, приоритет у кода; расхождение нужно зафиксировать.

## Границы документации

- Здесь хранятся **факты, решения, статус и ссылки**, а не история чатов.
- Документы ведёт ChatGPT. Только Codex изменяет код, конфигурации, тесты, скрипты и CI.
- Новые документы создавать по потребности, не заранее. Изменения upstream не описывать как внедрённые, пока не проверены.
- Не помещать в публичный репозиторий API-ключи, приватные рукописи, пользовательские конфиги и другие секреты.

**Внимание:** GitHub показывает удалённую ветку, а не текущее состояние локального ПК.
